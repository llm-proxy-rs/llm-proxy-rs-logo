# llm-proxy-rs logo

A playing-card back: a warm cream field, a copper pipe frame, and a centered mark. The field is `#fff9ef`, so the copper reads against the cream. The frame and the mark are that same copper pipe.

The mark is a straight copper pipe: constant width, a dark edge, copper across the tube, and a highlight down the lit side. An open mouth (rim, wall, dark bore) caps each end. The tube stops in the mouth, so the pipe is not longer than the opening, and the mouth stays clear of the frame. The frame is that same tube, bent around the card with round corners. A coupling mid-side joins the loop, so the frame reads as a bent pipe rather than a printed rule. The two runs meet in a sleeve connector, not a face-on circle. One frame, one centered mark, symmetric so it reads the same upside down. The card is 248×338, with no white border.
